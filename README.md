# Modern Engineering Portfolio

Personal engineering portfolio for Muhammad Abdul Rasyid, designed as a modern, responsive one-page portfolio with a cool gray, navy, and electric blue visual system.

## Tech stack

- HTML5
- Tailwind CSS
- Vite
- Vanilla JavaScript

## Development

```bash
npm install
npm run dev -- --host 0.0.0.0
```

Then open the local preview URL shown by Vite in the terminal.

## Production build

```bash
npm run build
```

The generated build output is placed in the `dist/` folder.
